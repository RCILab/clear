# Retained results

This directory contains only paper-facing final records and reports. The
authoritative inventory, protocol, run counts, and SHA-256 hashes are in
`PAPER_EXPERIMENT_MANIFEST.md`.

- `headline30/`: audited full CLEAR, component-free, and Vanilla CBF-QP
  320-mission records;
- `unicycle_*`: promoted main aggregates retained for direct recomputation;
- `smg_comparison_20seeds.json`: Doorway/Intersection comparison;
- `theorem_extension_audit.json` and `straight_bridge_scale_n8_n16.json`:
  theorem-domain and bounded-unicycle bridge evidence.

Development probes, tuning sweeps, partial shards, duplicate GIFs, and the
superseded 305-result archive are intentionally excluded.
